## Featured Projects

### [Help Desk Pro](https://github.com/JoaoPauloSCosta/helpdeskpro)

A ticket management web application for technical support teams, built as a Laravel monolith with Inertia.js and Vue 3.

- **Problem it solves:** keeps support requests, ownership and deadlines in one place.
- **Key features:** ticket lifecycle (open, assign, pend, resolve, reopen, close); SLA policies by priority with pause and resume for pending tickets; role-based permissions; public comments and internal notes; attachments; audit history; technician performance dashboard; CSV export for administrators.
- **Stack:** Laravel 12, PHP 8.2+, Inertia.js, Vue 3, TypeScript, Tailwind CSS, MariaDB, Pest, Docker.
- **Note:** the interface and documentation are in Brazilian Portuguese.

### [Health Check for GLPI](https://github.com/JoaoPauloSCosta/glpi-health-check)

A free, open source plugin that diagnoses a GLPI installation and explains each finding with step-by-step guidance. It is strictly advisory: it never changes GLPI files, the database or settings.

- **Problem it solves:** helps administrators find update, configuration and performance risks before they turn into incidents.
- **Key features:** health score dashboard; problems sorted by criticity, each with impact, probable cause and recommended fix; score trend and comparison with the previous run; full and light diagnostics; report export; English and Brazilian Portuguese interface.
- **Stack:** PHP, GLPI plugin architecture (GLPI 10.0, 11.0 and 12.0), GPLv3+.

### [Agendamento Pro](https://github.com/JoaoPauloSCosta/agendamentopro)

An appointment scheduling system for clinics, deployed on Vercel ([live app](https://agendamentopro.vercel.app), sign-in required).

- **Problem it solves:** organizes appointment scheduling for clinics.
- **Key features:** screens for appointments, clients, professionals and specialties, plus sign-in and password recovery.
- **Stack:** Nuxt, Vue 3, TypeScript, Pinia, Tailwind CSS, Supabase.

### [Nutrition Calculator](https://github.com/JoaoPauloSCosta/calculadoranutri)

A web application that uses the OpenAI API to analyze a photo or a text description of a meal.

- **Problem it solves:** gives a quick nutritional estimate of a meal without manual calculation.
- **Key features:** analysis from an image or a text description; breakdown of calories, protein, carbohydrates, fat and fiber.
- **Stack:** Next.js (App Router), React 19, TypeScript, Tailwind CSS, OpenAI API.

## Private & Proprietary Projects

### GLPI Chat & Automation

**Private / Proprietary Project**

A real-time communication and workflow automation solution integrated with GLPI, designed to improve IT service desk operations.

- **Problem it solves:** gives users and technicians a direct channel inside GLPI, with organized queues and a ticket created automatically when a chat is taken.
- **Key features:** chat queues organized by technician groups; first-come service order, so technicians take the next chat in line; protection against two technicians taking the same chat; transfers between technicians and queues; audible alert for new messages; works in the standard and simplified (Self-Service) GLPI interfaces.
- **Automation:** a ticket is created automatically when a chat is taken, with messages recorded as follow-ups and a solution on closing; chats are distributed to technicians through group queues.
- **Stack:** PHP, JavaScript, GLPI 10 plugin.

> *Source code is private due to proprietary project ownership.*
